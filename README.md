# 海戰棋 BATTLESHIP：Socket 多人連線對戰

2～4 人混戰＋觀戰，區網自動搜尋 Server，只用 Python 標準函式庫，不用安裝任何套件。

| 檔案 | 用途 |
|---|---|
| `開始遊戲_Windows.bat`／`開始遊戲_Mac.command` | **雙擊就能開遊戲** |
| `開放防火牆_Windows.bat` | 當主機的 Windows 電腦執行一次，一次開放所需的 Port |
| `client_gui.py` | 遊戲畫面：自動搜尋、當主機、大廳、對戰、觀戰、封包監看 |
| `server.py` | 裁判伺服器；可以單獨執行，也可以在 GUI 裡按「我當主機」 |
| `bot.py` | 機器人玩家，用來測試或補人數 |
| `protocol.py` | 共用：JSON Lines 收發、艦隊規則、UDP 自動搜尋 |

---

## 一、最快的玩法（不用輸入 IP）

1. 每台電腦都要裝 Python 3（python.org；Windows 安裝時記得勾「Add Python to PATH」）。
2. 所有人連**同一個 Wi-Fi 或手機熱點**。學校 Wi-Fi 常擋住裝置互連，建議用手機熱點。
3. **主機那台**（Windows）先雙擊 `開放防火牆_Windows.bat`，跳出的視窗按「是」。這一步只要做一次。
4. **主機**：雙擊 `開始遊戲`，輸入暱稱，按 **「★ 開 Server 並進入」**。
5. **其他人**：雙擊 `開始遊戲`，輸入暱稱。左邊「區網中的 Server」會**自動出現主機**，點一下就連上。
6. 主機在大廳選 2／3／4 人，按「建立房間」；其他人在右邊房間列表按「加入」，想看的人按「觀戰」。

> 自動搜尋找不到時，用畫面上的「③ 手動輸入 IP」：輸入主機視窗右上角顯示的 `★ 主機 192.168.x.x:9100`。
> Mac 第一次雙擊 `.command` 如果被擋，請按右鍵選「打開」。當主機時，系統詢問「是否允許接受連入連線」，請按「允許」。

## 二、畫面說明

- **板子顏色：** 左下「顏色」列有 8 種顏色可以點選，**只能在等待和佈陣時選，開戰後就鎖定**（顯示「已鎖定」，Server 也會拒絕更換）。同一房間不能重複（別人在用的會變暗並打叉），加入房間時會自動分配一個空著的顏色。**你的板子、縮圖、砲台、聊天文字、戰況裡你的名字，都用同一個顏色**，大家看到的都一樣。
- **左邊：全員海域縮圖。** 每位玩家一個顏色；外框亮起的是正在開火的人，白框是目前大圖顯示的人。點縮圖就能切換大圖。
- **中間：大圖。** 輪到你時，自動顯示你選的攻擊目標（點左邊縮圖可以換目標），滑鼠移上去會出現準星，下方的砲台也會跟著轉向。
- **開火動畫：** 砲彈以拋物線飛過去，落地才揭曉結果。沒中會濺起水花，留下 X；命中會爆炸、畫面震動，之後持續燃燒；擊沉的船變成焦黑船身並冒煙。
- **大圖固定在你的目標：** 玩家的大圖固定顯示自己唯一能打的那片海域，不會因為別人開火而跳走。別人打你時，左邊你的縮圖會出現落點效果、外框閃爍，標題也會提示「○○ 正在瞄準你」。想看其他海域就點縮圖，輪到你時會自動回到目標。觀戰者與已淘汰的人則會跟隨每一發砲彈。
- **大圖上方的船艦列：** 顯示這位玩家 5 艘船的狀態，被擊沉的會變黑。佈陣時點這一列可以切換要放的船。
- **右邊：戰況欄**（戰況紀錄＋聊天）。拖曳它左邊的分隔線可以調整寬度；按上方的「◧ 戰況：開／關」可以收起來，讓大圖置中。
- **左下：8 種表情嘲諷**（笑死、太帥、生氣、哭哭、吐舌、想睡、爆炸、GG）。點一下，所有人都會看到你的縮圖和大圖旁冒出表情（每 1.2 秒最多一次）。戰況欄關掉時也能用。
- **◑ 遮住我的船（防偷看）：** 左下角的按鈕。按下後，大圖和縮圖上你還沒沉的船都不顯示，避免旁邊的朋友偷看；再按一次就恢復。
- **其他艦隊剩餘：** 每張縮圖下方，以及大圖左下角，都會顯示其他玩家剩幾艘、哪幾艘被擊沉。
- **＋ 加入機器人：** 房主在等待中的房間按一下，Server 就會加入一個機器人（它是真正透過 TCP 連進來的 Client）。房裡沒有真人時，機器人會自己離開。

## 三、斷線與暱稱

- **暱稱：** 預設會隨機產生一個（例如「迷路的章魚」），按「隨機」可以再換；如果暱稱被用掉了，會自動幫你換一個。
- **斷線時：** 畫面上方會出現紅色橫幅，程式每 2.5 秒自動重連一次，Server 會保留你的位置 30 秒。不想等了，就按橫幅上的 **「放棄並回首頁」**。
- **程式當掉或被關掉：** 登入憑證存在本機（`~/.battleship_session.json`）。用**同一台電腦、同一個暱稱**重開並連回同一台 Server，就會直接回到原本的對局，不會再出現「暱稱已有人使用」。
- **心跳偵測：** Client 每 5 秒送一次 PING。Server 超過 20 秒沒收到任何資料就判定斷線；Client 超過 15 秒沒收到 Server 回應，也會自己判定斷線並重連。這可以處理「Wi-Fi 突然斷掉，但 TCP 還沒發現」的情況。

## 四、遊戲規則

- 10×10 海域，每人 5 艘船：航空母艦 5 格、戰艦 4 格、巡洋艦 3 格、潛艇 3 格、驅逐艦 2 格。
- 佈陣：點格子放船，右鍵或 R 旋轉，也可以按「隨機」；完成後按「準備完成」。
- 開戰順序由 Server 隨機決定，之後依座位輪流。
- **開局抽籤：** 開戰時 Server 隨機排出一個圈，例如 A → B → C → D → A。**每人只能打箭頭指向的下一位**（A 只能打 B、B 只能打 C、C 只能打 D、D 只能打 A），回合也照這個順序輪。有人淘汰就跳過他，例如 C 淘汰後 B 改打 D。抽籤結果顯示在畫面上方，打錯人會被 Server 拒絕（`E_TARGET`）。
- **命中（或擊沉）可以繼續打同一個目標；沒打中才換下一個人。**
- 被打過的格子會整格變色：**沒中 = 淺色格加 X**，命中 = 黑底加火焰；**擊沉 = 直接顯示整艘船**（不加火焰或煙）。滑鼠移到打過的格子上，準星會變紅並顯示「已打過」。
- 船全部被擊沉就淘汰，最後存活的人獲勝。
- 每回合 30 秒，逾時就跳過；連續 3 次逾時直接淘汰。
- 3、4 人房沒坐滿時，房主可以提早按「開始遊戲」（至少 2 人）。
- 結束後，所有人都按「再來一局」就會重新開始。
- **觀戰者**看得到所有人的開火結果，但**看不到任何人的船**，遊戲結束才會公開。

## 五、網路設計（對應課堂知識）

| 用途 | 協定 | Port | 為什麼 |
|---|---|---|---|
| 自動搜尋 Server | **UDP** 廣播 | 9101 | 不用先建立連線，就能「對整個區網喊一聲」；丟了也沒關係，2.5 秒後會再找一次 |
| 遊戲資料 | **TCP** | 9100 | 開火、命中結果不能遺失，也不能亂序，所以用可靠傳輸 |

**自動搜尋流程：** Client 送出 `BATTLESHIP_DISCOVER_V1` 到 `255.255.255.255:9101`（廣播位址）→ Server 回覆 `{"name":…, "port":9100}` → Client 從回覆封包的**來源位址**得知 Server 的 IP → 再用 TCP 連線過去。

**TCP 連線：** Server 執行 `socket()` → `bind(("0.0.0.0", 9100))` → `listen()` → `accept()`，每個連線開一條 thread；共享資料用 `threading.RLock` 保護。Client 執行 `create_connection()`，完成三向交握後才開始收送資料。

**訊息格式：** JSON Lines，每則訊息一行，以 `\n` 結尾。TCP 是位元組串流、不保留訊息邊界，所以接收端先累積緩衝區，再依換行切出完整訊息。

**權威伺服器：** 所有人的船只存在 Server。Server 送出的 STATE 會**依身分過濾**：玩家只拿得到自己的船，觀戰者誰的船都拿不到。命中判定、輪到誰、能不能再打一次，全部由 Server 決定。

| 方向 | 訊息範例 |
|---|---|
| C→S | `{"cmd":"CREATE","capacity":3}`　`{"cmd":"JOIN","code":"8743"}`　`{"cmd":"JOIN","code":"8743","spectate":true}` |
| C→S | `{"cmd":"PLACE","ships":[{"id":"carrier","x":1,"y":0,"dir":"H"},…]}` |
| C→S | `{"cmd":"FIRE","target":"小華","x":4,"y":5}`（target 必須是 Server 指定的本回合目標） |
| C→S | `{"cmd":"ADD_BOT"}`　`{"cmd":"EMOTE","kind":"laugh"}`　`{"cmd":"COLOR","color":"#a78bfa"}`　`{"cmd":"PING"}` |
| S→C | `{"event":"STATE",…,"turn":"阿明","turn_target":"小華"}`（本回合誰打誰） |
| S→全房 | `{"event":"SHOT","by":"阿明","target":"小華","at":"E6","result":"hit"}` |
| S→全房 | `{"event":"AGAIN","player":"阿明","msg":"阿明 命中，繼續開火！"}` |
| S→全房 | `{"event":"ELIMINATED","player":"小華",…}`　`{"event":"GAME_OVER","winner":"阿傑",…}` |
| S→大廳 | `{"event":"LOBBY","rooms":[{"code":"8743","phase":"BATTLE","players":[…]}]}`（房間有變動就即時推播） |

## 六、錄影證據（兩台主機 10%）

- 主機視窗右上角的黃色標籤 `★ 主機 192.168.x.x:9100`，以及下方的 **Server 日誌**欄。
- 另一台的 Client 右上角：`Server 192.168.x.x:9100`、`本機 192.168.y.y:xxxxx`，兩邊 IP 不同。
- Server 日誌會出現 `[UDP ] 回應 192.168.y.y 的自動搜尋` 和 `[CONN] 192.168.y.y:xxxxx 已連線`，來源是另一台的 IP。
- 同一次開火，三個地方會對得起來：Client 封包監看的 `→ {"cmd":"FIRE",…}`、Server 日誌的 `[FIRE] 阿明 -> 小華 E6：hit`、兩邊畫面的更新。

## 七、異常處理（加分 5%）

| 異常 | 怎麼觸發 | 結果 |
|---|---|---|
| **沒輪到就開火** | 別人回合時點對手海域 | `E_TURN`「還沒輪到你」 |
| **重複開火** | 點已經打過的格子 | `E_REPEAT`「小華 的 I7 已經被打過了」 |
| 打錯對象 | 對抽籤目標以外的人開火 | `E_TARGET`「你只能攻擊 B（開局抽籤決定）」 |
| 表情太頻繁 | 連點表情 | `E_COOLDOWN` |
| 顏色重複 | 點別人正在用的顏色 | `E_COLOR`「這個顏色 A 已經在用了」 |
| 網路突然斷掉 | 關掉 Wi-Fi | 心跳逾時後，Server 判定斷線並保留座位；Client 自動重連，或按「放棄並回首頁」 |
| 程式被強制關閉 | 直接關掉視窗 | 用同暱稱重開即回到原局（本機保存的憑證） |
| **對局中斷線** | 拔網路，或關掉一位玩家的程式 | 全房暫停並顯示「等待 30 秒重連」；斷線方自動重連後回到原局；逾時沒回來就淘汰，其他人繼續打 |
| 對局中離開 | 按「離開房間」 | 該玩家淘汰，座位顯示「已離開」，其他人繼續 |
| 房間已開打還想加入 | 加入交戰中的房間 | 提示改用「觀戰」 |
| 非房主按開始 | 非房主送出 START | `E_OWNER` |
| 暱稱重複 | 同名登入 | `E_NAME_TAKEN` |
| 佈陣不合法 | 自製 Client 送出重疊或出界的船 | `E_PLACE`（GUI 擋一次，Server 再擋一次） |
| 非法資料 | 送出非 JSON 的內容 | `E_BAD_REQUEST`，Server 不會崩潰 |

GUI 刻意不在本地擋「沒輪到你」和「重複開火」，交給 Server 判斷，影片才看得到 Server 的驗證。

## 八、指令列用法（選用）

```
python server.py --port 9100 --turn 30 --grace 30         單獨開 Server（不用 GUI）
python client_gui.py --host 192.168.1.20 --name 阿明      直接連線
python bot.py                                             機器人：自動搜尋 Server 並快速配對
python bot.py --join 8743 --rematch                       機器人加入指定房間
python bot.py --create 3                                  機器人建立 3 人房
python bot.py --watch 8743                                機器人觀戰（終端機文字轉播）
```

## 九、目前限制（計畫書要如實寫）

- 對局只存在 Server 記憶體裡；**主機關掉視窗，Server 也會跟著關**，所有對局都會消失。
- 只用暱稱加上一次性 token 識別，沒有帳號密碼。
- 自動搜尋依賴區網廣播；有些網路（學校、公司）會擋，這時改用手動輸入 IP。
- 期末延伸方向：網頁版前端、戰績排行榜（資料庫）、道具或技能、跨網段連線。
